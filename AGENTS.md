# Kumbh Labs Website Guidelines

## Overview

This repository contains the official website for Kumbh Labs, an R&D initiative for an AI-first Kumbh Mela.

## Architecture

- **Framework**: TanStack Start with TanStack Router
- **Build tool**: Vite + Nitro (cloudflare-module preset)
- **Styling**: Tailwind CSS v4 with custom serif/sans/mono font scales
- **Forms**: OpenSourceUI ContactForm component with honeypot spam protection and server-side relay
